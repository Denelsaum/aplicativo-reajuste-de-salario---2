# Aplicativo de Aumento Salarial

Aplicativo Android que permite ao usuário inserir o salário de um funcionário e calcular o novo salário com base em um percentual de aumento (40%, 45%, 50%).

---

## 🏗️ **Tecnologias Utilizadas**
- **Linguagem:** Java
- **IDE:** Android Studio
- **Interface:** XML
